SURVIVAL WORLD - GitHub Pages mobile upload

Upload index.html to the root of the GitHub repository.
You may also upload SurvivalWorld-devlog.txt and test-survivalworld.py (optional).
Then enable Settings > Pages > Deploy from a branch > main > /(root).

Play: https://ssoriniulian-lang.github.io/SurvivalWorld/

Note: this is a browser prototype, not real multiplayer. The 3D engine is loaded from Three.js CDN, so the browser needs internet access.
